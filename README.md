# Violet Quartz Co.

A luxury-inspired jewelry e-commerce website built using HTML, CSS, and JavaScript.  
Violet Quartz Co. showcases handcrafted jewelry collections including rings, necklaces, earrings, bracelets, and exclusive vault specials.

---

##  Features

- Responsive multi-page jewelry website
- Elegant luxury-themed UI design
- Product collections with modal previews
- Shopping cart system using Local Storage
- Add-to-cart functionality
- Quantity management in cart
- Interactive product modals
- Contact form with success notification
- About page with company story and branding

---

##  Functionalities

### Product Modal
Clicking a product image opens a modal showing:
- Product Image
- Product Name
- Material
- Description
- Price

### Shopping Cart
Users can:
- Add items to cart
- Increase/decrease quantity
- Remove items
- Clear cart
- Simulate checkout

Cart data is stored using browser Local Storage.

##  How to Run the Project

1. Download or clone the repository:

```bash

```

2. Open the project folder.

3. Run `index.html` in your browser.
